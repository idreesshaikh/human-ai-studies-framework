# Start a study

Build the platform and run the server as described in the [repository README](https://github.com/idreesshaikh/human-ai-studies-framework/blob/main/README.md). Open the researcher workspace and create a project and study. Record the protocol in Setup, estimate recruitment in Plan, connect participants in Run, and inspect captures and inclusion decisions in Data.

The [planner guide](https://github.com/idreesshaikh/human-ai-studies-framework/blob/main/docs/planner.md) describes protocol v6, typed surveys, pilot updates, and control-arm audit limits. No demo or rehearsal sessions are inserted automatically. Auth configuration remains available.
