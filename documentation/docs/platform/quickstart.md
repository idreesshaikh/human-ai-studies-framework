# Start a study

This page takes a new study from an empty list to its first participant link.
It assumes PHOENIX is running; see [Run PHOENIX yourself](index.md#run-phoenix-yourself).

## 1. Create the study

On **Studies**, choose **New study**, give it a name, and choose
**Create study**. The study opens on its **Setup** tab.

## 2. Describe it, or start from a template

On **Setup**, describe what you want to learn and the
[design chat](design-conversation.md) proposes decisions for you to accept or
reject. If you already know the design, choose
**Start from details or an example**, then
**Enter the protocol details directly**.

You can also start from **Templates** in the sidebar. **Use this template**
creates a new study with that template's protocol and opens it on **Plan**.
**Describe your study instead** opens the design chat.

  ![The Templates page with a featured template and the option to describe a study instead](../assets/screens/templates-light.webp#only-light)
  ![The Templates page with a featured template and the option to describe a study instead](../assets/screens/templates-dark.webp#only-dark)

## 3. Apply the protocol

When the [protocol draft](protocol-draft.md) has what you need, choose
**Review draft**, check the changes, and choose **Apply protocol**. Nothing
reaches a participant before this step.

## 4. Plan, run, read

1. **Plan:** estimate how many participants the analysis needs.
   See [Plan](planning.md).
2. **Run:** create participant links and send them. See
   [Participant links](participants.md).
3. **Data:** check each session as it arrives, tag pilots, and record inclusion
   decisions. See [Data](data.md).

## Explore the example first

The example server from [Run PHOENIX yourself](index.md#the-example-study)
includes a finished study, **Example copilot and bug fixing synthetic data**: a
within-subjects comparison of debugging with and without Copilot, with a saved
plan, 24 illustrative links and simulated sessions. Its links cannot connect an
editor, and its sessions are synthetic, so nothing in it is a finding.

The [walkthrough](https://github.com/idreesshaikh/human-ai-studies-framework/blob/main/docs/demo-walkthrough.md)
is a script for presenting the example.
