# Literature corpus — human-AI developer studies

Curated for the Masters project **"Framework for Conducting Human-AI Studies"**.
The point of this corpus is the *motivation* behind the framework: understanding
how humans and AI agents actually work together on software, how such studies are
instrumented and measured, and where current methodology falls short — not just
building a platform.

> **This file is Tier A of the corpus** (FR-LIT-8): the hand-curated
> seeds, each with a human-written "why". **Tier B** — the harvested
> extension toward the 1,000-paper corpus — is generated by
> `scripts/corpus_harvest.py` into `CORPUS.md` + `corpus-index.json`
> (citation snowballing from these seeds; quality-gated; every entry
> API-verifiable; never hand-edited). Add papers *here* only with a
> rationale; everything else belongs to the pipeline.

- **58 papers**, all PDFs in this folder (`<file>.pdf` matches the *File* column).
- ★ = paper from the professor's / our original reading list (see `../Papers.png`);
  unmarked = found via our own related-work search.
- PDFs are **gitignored** (≈136 MB); this index is the tracked record. Re-fetch any
  PDF from its arXiv link.
