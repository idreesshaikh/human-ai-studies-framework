# Historical example artifacts

`pilot-2026/` contains an older protocol, synthetic analysis report, notebook and
data dictionary. These are historical examples, not participant findings or a
validation of the current pipeline. The former `middleware simulate` command and
worked-example regression test were removed; these artifacts cannot be regenerated
with that command in the current tree.

For current planning methods, assumptions and supported analyses, see
[the planner documentation](../planner.md). Current notebook and export routes use
the study's recorded protocol and captured data. Pilot sessions must be tagged and
kept separate from confirmatory findings.

`demo-rehearsal/` also contains historical notebook and dictionary artifacts; its
README records the removal of the rehearsal flow.
